# Skill: audit-performance

**Mission:** Analyze and document performance characteristics and bottlenecks.

**Inputs:**
- API source code
- Database schema and queries
- Frontend bundle analysis
- Load test scripts

**Outputs:**
- Performance diagnostic report
- Caching strategy recommendations
- Query optimization recommendations

**Workflow:**
1. Review database query patterns and indexes
2. Review caching implementation
3. Review frontend bundle size
4. Review API response times
5. Generate performance recommendations

**Validation:**
- All performance dimensions covered
- Specific optimization suggestions with effort estimates

**Deliverables:**
- Performance diagnostic section in docs/diagnostics/
- Performance optimization tasks in roadmap
