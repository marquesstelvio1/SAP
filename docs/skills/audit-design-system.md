# Skill: audit-design-system

**Mission:** Audit UI component library for consistency, accessibility, and design token compliance.

**Inputs:**
- @saptm/ui source code
- Design tokens
- Storybook stories
- Component tests

**Outputs:**
- Design system audit report
- Component coverage analysis
- Token compliance report

**Workflow:**
1. Review design token definitions
2. Audit component token usage
3. Review Storybook coverage
4. Review dark mode support
5. Review accessibility patterns
6. Generate improvement recommendations

**Validation:**
- All components checked for token compliance
- Dark mode support verified
- Accessibility patterns reviewed

**Deliverables:**
- Design system diagnostic section in docs/diagnostics/
- Design system improvement tasks
