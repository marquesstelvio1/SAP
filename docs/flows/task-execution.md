# Flow: Task Execution

## Entry gate

- task has objective
- task has domain
- task has done criteria
- task has owner agent
- task has linked rules and dependencies

## Execution

1. Planner agent validates scope.
2. Domain agent implements within the allowed surface.
3. QA agent generates tests and regression scope.
4. Git manager agent drafts branch, commit, and PR metadata.
5. Governance checks run before merge and release.

## Exit gate

- tests generated or updated
- docs generated or updated
- changelog entry generated
- PR draft generated
- risk status recorded
