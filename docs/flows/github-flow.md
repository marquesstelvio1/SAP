# GitHub Flow

## Standard

1. Diagnostic or roadmap item generates a task bundle.
2. Task bundle generates a branch using the branch standard.
3. Work is executed and validated locally and in CI.
4. AI drafts the PR using the approved template.
5. Review gates validate risk, tests, docs, and changelog.
6. Merge triggers release or environment promotion logic.

## Mandatory PR sections

- context
- linked task
- impacted domains
- risk
- validation evidence
- rollout and rollback
