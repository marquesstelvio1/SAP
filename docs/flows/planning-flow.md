# Flow: Planning

**Phase:** 10 — Execution Pipeline

---

## Purpose
Convert diagnostic findings into executable tasks.

## Inputs
- Diagnostic reports
- Executive summary

## Outputs
- Task definitions
- Sprint plans
- Roadmap

## Steps
1. Extract all findings from diagnostics
2. Prioritize by severity and dependencies
3. Create task definitions with acceptance criteria
4. Assign effort estimates
5. Assign owner agents
6. Sequence into sprints
7. Create roadmap document

## Checkpoints
- [ ] All critical findings have tasks
- [ ] All high findings have tasks
- [ ] Dependencies between tasks identified
- [ ] Effort estimates provided
- [ ] Owner agents assigned

## Quality Gates
- Tasks have clear acceptance criteria
- Dependencies documented
- Effort estimates realistic
- Priority aligned with diagnostic severity
