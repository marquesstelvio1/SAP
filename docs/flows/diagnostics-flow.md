# Flow: Diagnostics

**Phase:** 10 — Execution Pipeline

---

## Purpose
Identify problems, risks, and technical debt across all engineering dimensions.

## Inputs
- Repository analysis
- Source code

## Outputs
- 14 dimension diagnostic reports
- Executive summary

## Steps
1. Analyze frontend
2. Analyze backend
3. Analyze database
4. Analyze auth
5. Analyze RBAC
6. Analyze multi-tenancy
7. Analyze security
8. Analyze performance
9. Analyze testing
10. Analyze observability
11. Analyze accessibility
12. Analyze design system
13. Analyze CI/CD
14. Analyze developer experience

## Checkpoints
- [ ] Frontend architecture reviewed
- [ ] Backend services reviewed
- [ ] Database schema and queries reviewed
- [ ] Auth flows and configuration reviewed
- [ ] Security posture assessed
- [ ] Test coverage measured
- [ ] Observability setup reviewed
- [ ] Design system audited

## Quality Gates
- Each report has: Current State, Problems, Debt, Risks, Impact, Priority, Actions, Effort, Owner
- Executive summary prioritizes critical issues
- All 14 dimensions covered
