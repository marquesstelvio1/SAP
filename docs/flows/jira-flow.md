# Jira Flow

## Standard

1. Diagnostic creates or updates an Epic.
2. Epic is decomposed into Stories and technical Tasks.
3. Tasks are linked to risks, rules, and blockers.
4. Status transitions follow governance gates.
5. Release state updates are mirrored back into reports.

## Recommended statuses

- Discovery
- Ready
- In Progress
- In Review
- Ready For Release
- Released
- Stabilizing
- Done
