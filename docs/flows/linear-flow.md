# Linear Flow

## Standard

1. Findings become initiatives or projects.
2. Features become issues with domain tags and priority.
3. AI enriches issues with acceptance criteria and risk notes.
4. PR links and release notes are attached automatically.
5. Closed issues emit changelog and documentation updates.

## Recommended labels

- ai-generated
- requires-approval
- contract-change
- auth-critical
- performance
- observability
- release-blocker
