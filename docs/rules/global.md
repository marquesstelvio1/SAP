# Global Execution Rules

1. Read the local context before proposing or applying a change.
2. Never bypass governance gates for auth, contracts, data, or release-critical flows.
3. Always create or update tests for impacted critical paths.
4. Always create or update documentation for behavioral changes.
5. Always record assumptions, risks, and rollback notes.
6. Always preserve observability on production-impacting changes.
7. Never change more domains than the task explicitly allows without escalation.
