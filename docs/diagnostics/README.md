# Diagnostics

This folder stores structured diagnostics that feed the workflow engine.

Each diagnostic must include:

- current state
- risks
- impact
- urgency
- recommended epic
- suggested owner agent
- evidence

Recommended file convention:

- `frontend-YYYY-MM-DD.md`
- `backend-YYYY-MM-DD.md`
- `auth-YYYY-MM-DD.md`
- `platform-YYYY-MM-DD.md`

Diagnostics are inputs, not final outputs. Every accepted finding must flow into roadmap, tasks, and stabilization.
