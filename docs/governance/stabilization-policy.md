# Continuous Stabilization Policy

## Goal

Prevent delivery speed from outrunning system stability.

## Rules

- Every release must reserve stabilization capacity.
- Every incident must become a diagnostic artifact.
- Every recurring failure must create a rule, test, or automation.
- Every high-severity regression must produce a prevention action.

## Required weekly outputs

- open risk report
- flaky test report
- performance drift report
- documentation drift report
