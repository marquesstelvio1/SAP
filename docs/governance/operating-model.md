# Governance Operating Model

## Decision split

- Humans approve priority, scope, release timing, and exceptions.
- AI executes planning, implementation, testing, documentation, and reporting within approved scope.

## Mandatory gates

1. Scope gate
2. Contract gate
3. Auth and security gate
4. Test gate
5. Docs and changelog gate
6. Release gate

## Escalation triggers

- cross-domain breaking change
- payment or auth regression risk
- data retention or privacy impact
- unclear business rule
- low observability on critical path
