# `@saptm/rpc`

oRPC contract package.

Current status:

- Contract metadata helpers implemented.
- Contract authorization helpers implemented.
- Typed RPC error catalog implemented.
- Trace header helpers implemented.
- oRPC builder wrapper implemented through `defineRpcContract`.
- No API contracts yet.
- No backend implementations.

Implementation must follow `docs/rpc/rpc-strategy.md`.
Authorization rules are documented in `docs/rpc/rpc-authorization.md`.
