# UI Rules

1. Do not create product pages before the design system is approved.
2. Use `@saptm/ui` for reusable UI primitives.
3. Use shadcn/ui components before custom markup.
4. Use semantic tokens, not raw color utilities.
5. Use form, table, dialog, sheet, and navigation patterns from the design system.
6. UI must not call database or backend implementation details directly.
7. Business status visuals must use approved token and badge semantics.
