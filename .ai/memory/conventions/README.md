# Project Conventions

This directory stores project conventions that all agents must follow.

## Convention Format

```markdown
# Convention: {name}

**Domain:** {domain}
**Approved:** YYYY-MM-DD
**Enforced By:** {plugin}

## Rule
{description of the convention}

## Rationale
Why this convention exists

## Example
{good example}

## Counter-Example
{bad example}

## Enforcement
How the convention is enforced
```
