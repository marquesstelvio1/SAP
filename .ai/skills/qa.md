# QA Skill

## Scope

Test strategy, test plans, regression coverage, acceptance criteria, and release evidence.

## Rules

- Every task needs explicit acceptance criteria.
- Critical mutations require success, forbidden, validation, and audit tests.
- E2E tests begin after design-system and feature approval.
- Release readiness requires documented test evidence.

## Outputs

- Test plan.
- Regression risks.
- Coverage gaps.
- Release recommendation.
