# DevOps Skill

## Scope

PNPM, Turborepo, Biome, dotenvx, tsup, Changesets, Playwright, GitHub Actions, release governance.

## Rules

- Keep workspace scripts reproducible.
- Do not commit secrets.
- CI must run lint, typecheck, tests, and build when implementation exists.
- Release workflows require rollback notes and migration review.

## Outputs

- Tooling changes.
- CI changes.
- Environment requirements.
- Rollback notes.
