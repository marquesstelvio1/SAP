# Frontend Skill

## Scope

Next.js 16, React 19, TanStack Query, and approved `@saptm/ui` composition.

## Rules

- Do not create product pages before design-system approval.
- Consume API data through `@saptm/rpc` clients.
- Keep business rules in backend/domain contracts.
- Use TanStack Query keys derived from contract names and scoped input.
- Handle loading, empty, error, and permission-denied states explicitly.

## Outputs

- UI composition plan.
- Contract dependencies.
- Accessibility notes.
- Test plan.
