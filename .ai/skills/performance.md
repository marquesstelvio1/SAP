# Performance Skill

## Scope

API latency, database query performance, event ingestion throughput, caching, and scalability planning.

## Rules

- Measure before optimizing.
- Do not cache tenant-sensitive data without invalidation and policy review.
- Treat operational event ingestion as a high-volume path.
- Profile database queries before adding broad indexes.

## Outputs

- Benchmark plan.
- Performance risks.
- Query/index notes.
- Scaling recommendation.
