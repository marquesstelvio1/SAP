# Reports

This directory stores all reports generated by the plugin system.

## Directory Structure

```
.ai/reports/
├── README.md              This file
├── archive/               Archived old reports
├── docs/                  Documentation updates
├── governance/            Governance reports
├── integrations/          Integration reports
├── pr-drafts/             PR draft reports
└── tests/                 Test reports
```

## Report Naming Convention

All reports follow this naming convention:

```
{plugin-id}-{date}.md
```

For example:
- `architecture-audit-2026-06-23.md`
- `security-audit-2026-06-23.md`
- `testing-audit-2026-06-23.md`

## Report Format

Every report must include:

```markdown
# {Plugin Name} Report
**Date:** YYYY-MM-DD
**Status:** PASS | FAIL | WARNING

## Summary
- Checks: {n}
- Passed: {n}
- Failed: {n}
- Warnings: {n}

## Findings
{detailed findings}

## Recommendations
{actionable recommendations}
```

## Archive Policy

- Reports older than 90 days are archived to `.ai/reports/archive/`
- Decision logs and ADRs are never deleted
